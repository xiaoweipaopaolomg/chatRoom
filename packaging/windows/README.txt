ChatRoom Windows x64 client
==========================

1. Extract the complete ZIP archive. Do not run the EXE from inside the ZIP.
2. Start ChatRoom.exe.
3. Enter the server address, port 7777, and a nickname.

For the current campus LAN server, use 172.20.168.83 as the address.
If Windows Defender Firewall asks for permission, private-network access is
sufficient. The program and bundled DLLs must remain in the same directory.

This client uses an unencrypted TCP connection. Use it only on a trusted LAN
or through a private VPN.
